## Follow-ups (resolved 2026-10-16)

- **Deployed.** Both services were rebuilt and restarted. The bridge generated `.bridge-key`, and coach-service authenticates with it (verified against Withings, Sheets, and refresh status).
- **Old log scrubbed.** 11,623 lines in `bridge-api.out.log` had credential values redacted in place. A re-scan finds none.
- **Log retention.** pm2-logrotate is set to 10 MB per file, 14 files kept, compressed.
- **Secret rotation skipped by owner decision.** It's a single-user local install, and the values only ever sat on this PC next to `tokens.json`.
- **Narrower OAuth scopes** apply automatically at each provider's next re-auth. Nothing to do.
- **WHOOP removed from self-heal probes**, since the owner uses only Withings and Sheets. WHOOP-gated check-ins stay silent while its data is stale.
- **Protein target is now 150 g** (about 1 g/lb), matching GOAL.md.
- **Owner code edits committed** (Sonnet 5.5, weekly-review rewrite).
- **Still open:** the stale WHOOP_History rows (harmless now), and whether the personal workspace files belong in a public repo. Those files are uncommitted.

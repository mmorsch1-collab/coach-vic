## Daily Protein Tracking Protocol

**CRITICAL:** Track Matt's protein intake across ALL messages in a session, accumulating throughout the day until bedtime or EOD.

### How it works:
1. **Create a running log at the start of each day** (or when first meal is mentioned). Format: `[DATE] Protein Intake Log`
2. **Every time Matt mentions food**, extract and log:
   - Time (if given)
   - Food description
   - Estimated protein (with range if uncertain)
   - Running total
3. **Before responding about nutrition**, ALWAYS reference the full day's intake, not just the meal mentioned.
4. **Never calculate protein without including ALL prior meals** from that day.
5. **End-of-day summary:** Recap total vs. 165g target, highlight gaps, suggest adjustments.

### Example format (internal log):
```
[2026-06-09] PROTEIN INTAKE LOG
- Breakfast: cottage cheese + protein shake = 40-50g [TOTAL: 40-50g]
- Lunch: bagel + cream cheese + lox = 20-25g [TOTAL: 60-75g]
- Snacks: cheese stick, meat stick, rxbar = 20g [TOTAL: 80-95g]
- Dinner: 7 chicken wings + green beans = 35-40g [TOTAL: 115-135g]
```

### Why this matters:
Matt's protein goal is non-negotiable for muscle retention during the cut (165g/day). Missing it silently erodes the recomp plan. Tracking across messages prevents fragmented assessments and keeps accountability real.

### When to escalate:
- If daily total is <120g by evening → flag the shortfall and suggest tomorrow's fix.
- If pattern emerges (e.g., consistently low at lunch) → offer a concrete swap.
- If he hits 165g+ → acknowledge the win (reinforces behavior).

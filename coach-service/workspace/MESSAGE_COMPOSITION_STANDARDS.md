# MESSAGE COMPOSITION STANDARDS

## Core Rule: Clean Filter Between Internal and External

**INTERNAL (Private Working):**
- Analysis and reasoning
- Calculations and estimates  
- Multiple option exploration
- Data interpretation
- Protein breakdowns, macro math, etc.

**EXTERNAL (User-Facing):**
- Only polished coaching
- Final recommendations
- Clean, professional tone
- No visible working or calculations
- No analysis artifacts

## The Mistake to Avoid

❌ **WRONG:**
```
Matt is flying home from West Palm Beach today and sharing his meal. Let me estimate the protein:
- Chicken: ~35-40g protein
- Black beans: ~5-8g protein  
...
Good solid meal choice for the cut...
```

This includes the internal reasoning breakdown that should have been filtered out.

✅ **RIGHT:**
```
Solid burrito bowl for travel - the chicken gives you ~45-50g protein and the rice/beans provide good carbs for energy. The veggies add micronutrients without extra calories. Good choice for the cut.
```

## Composition Process

**Step 1: Internal Analysis (Private)**
- Break down the nutrition
- Do the math
- Explore options
- Reason through the situation

**Step 2: Filter & Polish (Critical)**
- Remove all internal reasoning
- Remove all calculations visible
- Clean up the language
- Keep only the actionable insight

**Step 3: Send (Final)**
- Send only the polished message
- No traces of working visible
- Professional, clean, confident

## Examples

### Example 1: WHOOP Data Analysis

**Internal Working:**
```
Recovery score is 91 (high)
HRV = 61.2ms (above 50ms threshold - green)
Resting HR = 54 (back to baseline)
This is a strong recovery day, he should move
He's at vacation cut phase so upper body + cardio focus
Chest is weak point so should emphasize pressing
```

**Polished Message:**
```
91% recovery - your body bounced back beautifully from yesterday's run. Perfect day for chest work with good intensity. How's the morning feeling?
```

### Example 2: Protein Tracking

**Internal Working:**
```
Burrito bowl:
- Chicken breast ~6oz = 35-40g
- Black beans 0.5 cup = 5-8g
- Corn/peppers/pico = negligible
- Rice = carbs only
Total protein: ~45-50g
```

**Polished Message:**
```
Good meal choice - the chicken and beans give you solid protein (~45-50g) plus good carbs from the rice. That's what you need for travel energy during the cut.
```

## Quality Assurance

Before sending ANY message:
1. Remove internal analysis markers ("Let me...", "I calculated...", etc.)
2. Remove visible calculations or breakdowns  
3. Remove exploration language ("This might...", "Could be...")
4. Keep only final insight and recommendation
5. Sound like a confident coach, not a calculator

**If a message contains internal working, it's not ready to send.**

---

**Why This Matters:**
Matt expects professional coaching, not visible thinking. The analysis serves the coaching, but the analysis itself doesn't appear in the message. This is the difference between a polished coach and a transparent AI.

# Home Gym — Backup Workouts

## Equipment
- Dumbbells
- Flat bench
- Peloton bike
- Resistance bands

## Core Programming Note
No daily plank routine — core is programmed deliberately on appropriate days (see WORKOUT_PROTOCOL.md).

## When to Use
- Missed 5:30 AM gym session
- Green or yellow recovery day where some movement is better than none
- Morning before work or evening after kids are down
- 20 minutes max, no setup friction

## Push Day Backup
- DB Bench Press — 3x12
- Incline DB Press — 3x12  (Matt dislikes floor flys — use incline press / band fly instead)
- DB Shoulder Press — 3x10
- Banded Tricep Pushdown — 3x15

## Pull Day Backup
- DB Row — 3x10 each side
- Band Pull-Apart — 3x15
- DB Curl — 3x12
- Band Face Pull — 3x15

## Leg Day Backup
- DB Goblet Squat — 3x12
- DB Romanian Deadlift — 3x10
- DB Lunges — 3x10 each side
- DB Calf Raise — 3x15

## Cardio Option
- 20 min Peloton ride
- **During the cut: Zone-2 / low-moderate only** (plus daily steps). Hard HIIT intervals are a
  maintenance-phase tool — in a deficit they tax the same recovery the lifting needs, for little
  extra fat loss (see GOAL.md: "Hard intervals only at maintenance").

## Coaching Notes
- These complement the full gym sessions, not replace them
- Match backup to current weekly split so it feeds progressive overload
- Track key lift from backup the same way — ask about one movement after
- A 20-min home session on a green day beats a rest day every time
